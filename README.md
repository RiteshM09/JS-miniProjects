## 🛠️ How to Run These Projects Locally

Since these are plain web projects, they don't require any complex setup, installations, or node modules.

1. **Clone the repository to your computer:**
   ```bash
   git clone https://github.com
   ```
2. Navigate into the specific project folder:
   ```bash
   cd js-beginner-projects/01-random-quote-generator
   ```
3. Double-click the `index.html` file to run it instantly in your web browser (Chrome, Edge, Safari, Firefox).
